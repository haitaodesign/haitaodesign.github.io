🚀 03｜三步快速跑通国际互联网访问

想要快速访问国际互联网，第一步不是买软件，而是识别清楚你手中的设备，因为不同系统的门槛完全不同。

1. 识别你的设备 (核心第一步)

在开始之前，请确认你使用的设备系统：

  • Windows / MacOS: 门槛最低，直接下载安装包即可使用。
  • Android (安卓): 门槛较低，下载 APK 安装包导入配置即可。
  • iOS (iPhone/iPad): 门槛最高，需要海外 Apple ID 才能下载工具（Shadowrocket）。

Brett 的设备指南 (供参考)

我个人的方案是“多端同步”：

  • 办公: Mac 端开启小火箭或 Clash。
  • 移动: iPhone 长期挂载小火箭（配置模式），保证微信不卡顿的同时，Google/YouTube 随时秒开。

2. 三步快速跑通流程

不管什么设备，跑通的核心逻辑只有三步：

第一步：获取订阅 (通行证)

  1. 注册 VPN 服务商。
    • 新手/尝鲜首选: 魔戒 Mojie (IP直连注册) (支持国内网络直连访问，按流量计费，1元起用)
    • 进阶/稳定推荐: Forest / 奶猫 (专属邀请链接，作者含佣金支持)
    • 官方站点: https://cn.forest2026.com/ (若上述链接失效请从此获取最新地址)
  2. 购买一个基础套餐（建议新手先买 388.88元/200G 不限时 套餐，或魔戒的低额按量套餐）。
  3. （可选）如果你打算使用第三方客户端，请在后台找到“一键导入”或“复制订阅地址”。

第二步：安装客户端 (交通工具)

  • Forest 官方客户端 (推荐): Forest 现已提供官方客户端，支持全平台。请直接访问 下载与教程中心，下载对应的应用（内含详细图文与视频教程）。
  • 魔戒用户 (教程与客户端): 魔戒需配合第三方客户端使用。注册登录后，请直接访问 魔戒使用文档，获取各平台客户端的下载及详细配置指南。
  • iOS 补充说明: 针对 iOS 用户，若使用第三方工具，需准备美区 Apple ID 登录 App Store 下载 Shadowrocket (小火箭)。

第三步：配置与连接

  • 使用官方客户端: 下载后打开应用，直接登录账号即可一键连接使用，极其简单。
  • 使用第三方客户端: 将第一步获取的“订阅地址”粘贴到客户端中，点击“连接”开关。
    • 关键提醒: 模式务必选择 「配置 (Rule)」，不要选择「全局 (Global)」，否则国内 App 会变慢。

下一步: 跑通访问后，我们需要申请一个真正属于自己的谷歌账号 (Gmail)。
